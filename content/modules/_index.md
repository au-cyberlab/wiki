# What are modules?

Modules are how we package systems for the CyberLab to use. Each module can be a setup, a system, or a patch. 

Current Setup Modules:

 - Docker
 - Github
 - Kubernetes

Current System Modules:

 - Battery
 - DNS
 - Email
 - Expo IT
 - Forum
 - Gas
 - Hospital
 - Kafka
 - Mastodon
 - Minibus
 - Power System
 - Wazuh

Current Patch Modules:

 - DNSSEC
 - Expo IT Config
 - Mastodon Users
 - Wazuh Agent
