# Overview

The minibus booking system is a deliberately vulnerable website. The user
interface allows users to book minibus trips to tourist destinations. The
implementation, however, is deliberately designed with serious security flaws
and bugs for educational purposes.

## 1. Setup

To deploy the email system, add `minibus` to a lab configuration that is being deployed or your `deployment_config.yml` file.

## 2. Usage

The minibus server is exposed on the port 5173.

The default admin credentials are:

Username - `admin`

Password - `admin123`

Email - `admin@example.com`
